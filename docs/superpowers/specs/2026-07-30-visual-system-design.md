# 水光档案视觉系统设计

## 背景

公开档案、登录页和管理后台已经完成数据流、信息架构与安全边界重构，但视觉仍由早期的零散毛玻璃样式组成。当前主要问题是：

- 背景插画与正文直接竞争，部分区域的文字对比度依赖图片内容。
- 面板、按钮、输入框、标签和状态提示各自使用不同透明度、圆角与交互颜色。
- 公开卡片使用横向裁切展示竖版封面，作品识别效率不够高。
- 后台列表、表单、Bangumi 搜索和备份区域缺少一致的操作层级。
- 焦点态、禁用态、危险操作、减少动态效果等可访问性细节不统一。
- 管理列表与表单预览仍使用原生 `<img>`，保留了两个 ESLint 图片性能警告。

本阶段只优化视觉系统、页面布局和交互表现，不修改档案筛选语义、管理工作流、数据模型、API 或安全规则。

## 设计方向

采用“水光档案”方向：保留现有粉蓝水下插画作为产品识别，把它降为氛围层；内容使用更稳定的半透明瓷白表面、深靛文字和克制的樱粉/湖蓝强调色。

没有采用的方向：

- “编辑部档案”会获得更强的杂志感，但需要显著压暗或替换现有背景，会损失项目个性。
- “活力仪表盘”会增加渐变、图标和状态色，适合工具型后台，但会让公开档案过于嘈杂。

## 设计原则

1. **先读内容，再看背景**：插画保持可见，但任何正文都不依赖图片区域提供对比度。
2. **公开页像档案，后台像工作台**：共享同一套令牌，信息密度和布局各自服务使用场景。
3. **少量强调色承担明确语义**：樱粉用于主操作和选中态，湖蓝用于辅助信息，琥珀用于评分，红色只用于危险与错误。
4. **动效说明状态，不装饰等待**：进入、悬停和抽屉动效短促；尊重 `prefers-reduced-motion`。
5. **移动端不是桌面压缩版**：筛选使用底部抽屉，后台操作保持至少 44px 点击区域，封面和文字不被过度挤压。

## 视觉令牌

全局 CSS 定义以下语义令牌，不让业务组件直接决定视觉含义：

- 背景：`--canvas`, `--canvas-tint`, `--canvas-blue`
- 表面：`--surface`, `--surface-strong`, `--surface-soft`, `--surface-border`
- 文字：`--ink`, `--ink-muted`, `--ink-subtle`
- 强调：`--accent`, `--accent-strong`, `--accent-soft`, `--info`, `--warning`, `--danger`
- 阴影：`--shadow-sm`, `--shadow-md`, `--shadow-lg`
- 圆角：`--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-pill`
- 动效：`--duration-fast`, `--duration-normal`, `--ease-out`

保留 Tailwind 做布局与响应式编排；用少量稳定的语义类统一重复视觉：

- `.ui-panel` / `.ui-panel-strong`
- `.ui-field`
- `.ui-button` / `.ui-button-primary` / `.ui-button-secondary` / `.ui-button-danger`
- `.ui-icon-button`
- `.ui-chip` / `.ui-chip-active`
- `.ui-kicker`
- `.ui-focus`

旧 `.glass` 与 `.glass-input` 在本阶段保留兼容，但改为引用同一组令牌，避免未迁移区域突然失真。

## 全局画布与站点外壳

- 背景图片仍固定铺满视口。
- 在图片上增加从瓷白到浅蓝的半透明色洗，并在正文主区域提供更稳定的局部亮度。
- 去掉持续漂浮的闪光动画，改用静态的微弱光点；减少视觉噪音与合成开销。
- Header 使用紧凑的半透明导航条、明确的品牌标识和统一胶囊导航；移动端只保留必要入口。
- Footer 改为低对比度的细边界信息条，不再与页面内容竞争。
- 所有交互控件具有一致的 `focus-visible` 外圈；文本选择色与滚动条使用主题色。

## 公开档案

### Hero

- 采用左对齐的编辑式标题区，桌面端标题与统计信息形成两栏，移动端自然堆叠。
- “ANIME ARCHIVE”使用统一 kicker 样式；标题保持强对比。
- 三项统计改为紧凑的指标块，数字优先，说明次之。
- 运行计时器作为低优先级状态胶囊，不抢主标题。

### 筛选

- 桌面筛选面板不再浮在页面最顶端；保持 `sticky`，但使用正确的 Header 偏移，避免遮挡。
- 搜索框视觉优先级高于下拉项；控件全部使用统一 field。
- 标签默认轻量，选中时使用明确填充、勾选语义和可见焦点。
- 移动端保持“搜索 + 筛选”入口，底部抽屉增加遮罩关闭、标题层级和安全区间距。
- 活跃筛选与结果数形成同一工具行，清除操作保持次要层级。

### 年份、季度与作品卡片

- 年份容器使用稳定表面和更清晰的展开按钮；季度标题加入数量徽标与旋转箭头。
- 作品卡片封面改为 `2:3` 海报比例，减少 Bangumi 竖版封面裁切。
- 评分以封面右上角的琥珀徽标展示；标题、季度、标签和短评形成固定信息层级。
- hover 只做轻微上浮和阴影增强，键盘焦点与 hover 同等可见。
- 无封面、空筛选、加载失败使用统一状态面板和明确操作按钮。

### 详情抽屉

- 桌面维持右侧抽屉，移动端维持底部面板。
- 标题区使用封面与渐变遮罩；关闭按钮改为图标按钮并保留可访问标签。
- 元数据、标签、感想和外链使用统一表面与按钮语义。
- 打开时锁定页面背景滚动；关闭后恢复触发元素焦点。

## 登录与管理后台

### 登录

- 登录卡片使用强表面而不是依赖背景毛玻璃。
- 锁图标改为主题化图形容器，标题、说明、输入与按钮按单一任务垂直排列。
- 去掉长距离入场动画，只保留短促淡入；减少动态设置下禁用。

### 后台框架

- 页面标题、说明、退出操作形成一致 Header。
- 三个工作区导航使用分段控制器语义；选中项使用主题色细线与实色表面。
- 每个工作区使用统一强表面容器，标题、说明、主要操作和内容分层清楚。
- 搜索栏与“添加记录”按钮在桌面同一工具行，移动端堆叠。

### 记录、表单、Bangumi 与备份

- 记录列表提升封面尺寸和行间距，标题、季度、评分、编辑与删除形成稳定列；危险操作只在 hover/focus 时增强。
- 表单字段、分组标题、候选标签和评分预览统一使用设计令牌。
- Bangumi 搜索结果使用海报缩略图、标题/年份/话数层级和明确的“选择”动作。
- 备份概览、历史版本、导入预览和危险确认采用统一状态色，不改变现有恢复流程。
- 管理列表和表单封面预览迁移到 `next/image` 的 `unoptimized` 模式，继续支持外部 URL，同时消除原生图片警告。

## 响应式与可访问性

- 关键断点沿用 Tailwind 默认 `sm`, `md`, `lg`, `xl`，不新增自定义断点。
- 所有按钮、标签控件和图标按钮点击区域至少 44×44px，纯展示标签除外。
- 正文颜色在最弱表面上也保持可读；状态不仅依赖颜色，还提供文字或图标。
- `prefers-reduced-motion: reduce` 下禁用平滑滚动、闪烁、长过渡和位移动画。
- 对话框遮罩可点击关闭，Escape 行为保持；详情打开期间禁止背景滚动。
- 不自动播放、循环或新增与任务无关的动画。

## 测试与验收

### 自动化

- 组件测试验证关键语义类、海报比例、图片组件迁移、对话框滚动锁定和导航可访问名称。
- 现有交互测试必须全部保持通过。
- 运行 `npm test`、`npm run lint`、`npx tsc --noEmit`、`npm run build` 和 `git diff --check`。

### 浏览器检查

至少检查：

- 公开首页首屏、筛选区、年份/季度、作品卡片、详情抽屉和空筛选状态。
- 登录页稳定状态。
- 桌面宽度与窄屏宽度下无横向溢出；若浏览器控制面不支持调整视口，则用响应式 CSS 审查和组件测试补足。
- 键盘焦点、hover、打开/关闭详情和减少动态规则没有明显回退。

## 非目标

- 不替换背景图片或生成新的品牌插画。
- 不新增暗色模式。
- 不重做筛选、详情、添加、备份的业务流程。
- 不新增 UI 组件库或图标依赖。
- 不优化远程封面 CDN、缓存策略或图片代理。
- 不修改 API、存储、认证、限流或数据格式。
